# Landing Page — Bumerangue

Landing page da Bumerangue · Tecnologias Tributárias e Empresariais.

Arquivo único (`index.html`) sem build e sem dependências além do Google Fonts.
A narrativa é guiada pelo scroll: o bumerangue da marca é arremessado no hero,
cruza os capítulos e pousa no CTA final.

## Rodar localmente

```bash
python3 -m http.server 8781
# abra http://localhost:8781
```

Ou simplesmente abra o `index.html` no navegador.
